# SVG Skin Spec — Unified Visual Rules

All diagrams generated by this skill must follow these rules.

## Canvas & Font

- Canvas background: `#F8FAFC` (禁止纯白或纯灰)
- Global text color: deep blue-black `#0F172A`
- Module title: 11–12px bold
- Responsibility description: 9px regular
- Description text must use tinted low-saturation dark colors, **never pure gray**

## Card Width — Adaptive

- **Never** use fixed-width cards. Width is computed from the longest line of text inside the card.
- Text pixel estimation:
  - English / symbols × 5.5px
  - Chinese / Chinese punctuation × 11px
- `cardWidth = textPixelValue + 40px` (left + right padding)
- Horizontal gap between cards: fixed 14px

## Card Height — Line-driven

- Description text **must wrap**; never use single-line overflow-hidden.
- `totalLines = Math.ceil(textTotalPixels / availableWidth)`
- `cardHeight = 32px (title area) + totalLines × 13px (line height + gap)`
- Multi-line text wrapped in SVG `foreignObject` containing an HTML `<div>`, height computed by the formula above.

## Visual Details

- Outer container: rounded corners 8px
- Inner cards: rounded corners 6px
- Outer container left sidebar: 56px wide solid-color strip, white bold centered text
- Circular dependency edges: **red bold dashed lines**
- Auth guard / route guard nodes: orange highlight color
- Dependency category colors: core framework → blue family, infrastructure → green family, external API → purple family

## SVG Structure Template

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 W H">
  <!-- background -->
  <rect width="W" height="H" rx="8" fill="#F8FAFC"/>
  <!-- left sidebar -->
  <rect width="56" height="H" rx="8" fill="#SIDE_COLOR"/>
  <text x="28" y="H/2" fill="#fff" font-weight="bold" font-size="11"
        text-anchor="middle" dominant-baseline="middle">LAYER</text>
  <!-- cards use foreignObject for wrapped text -->
  <foreignObject x="70" y="Y" width="CW" height="CH">
    <div xmlns="http://www.w3.org/1999/xhtml"
         style="font-size:9px;color:#0F172A;padding:4px 8px;">
      <strong style="font-size:11px">Module</strong><br/>
      One-line responsibility description
    </div>
  </foreignObject>
</svg>
```

## Edge Styles

- Normal dependency: solid arrow, `#64748B` stroke, 1.5px
- Circular dependency: **dashed bold**, `#EF4444` stroke, 3px, `stroke-dasharray="8 4"`
- Redirect / programmatic nav: dotted arrow, `#94A3B8` stroke, 1.5px, `stroke-dasharray="4 4"`
- State transition: solid arrow, labeled with trigger action name
