Lightning Deep Link 测试页

点击以下链接，验证浏览器能否唤起 Lightning 应用：

  • 仅唤起应用
  • 仪表板
  • 工作台（带参数）
  • 定价模板
  • 成功页

使用说明：

1. 链接格式为 lightning://<路由路径>?<查询参数> ， 例如 lightning://desktop/console?id=123 → 应用内路由 /desktop/console?id=123 。

2. 需先安装打包后的应用（安装程序会注册协议）；macOS 开发模式下系统无法将协议链接转发到开发实例，请用打包产物测试。

3. 应用已在运行时点击链接，会聚焦现有窗口并跳转到目标页面。
