# Feature Sequence Diagram

针对项目中的核心功能（如：用户登录/大文件上传），通过全局检索真实代码，还原其完整的执行链路。

## 链路覆盖

- 从用户触发操作开始，完整追踪：UI 组件事件 → API 请求调用 → Store/全局状态更新 → 视图响应式渲染

## 标注规范

- 清晰标注每一步涉及的组件名称、方法名/Hook 名、以及传递的核心数据

## 输出

- 保存为 `./docs/sequence-<功能名>.svg`

## 扫描策略

1. 用户指定功能名（如"登录"、"上传"）
2. 找到触发入口组件（按钮 click / 表单 submit 等）
3. 追踪事件 handler → 调用的 API 方法 → 传入参数
4. 追踪 API 返回 → Store action / mutation 调用 → 状态更新
5. 追踪状态变更 → 组件 watch / computed 响应 → UI 渲染更新
6. 每一步标注：组件名、方法名、数据字段名、数据类型
